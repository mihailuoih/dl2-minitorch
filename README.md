### Задача 0.5

Датасет: `Simple`.

Параметры:
```text
linear.weight_0_0 = -10.0
linear.weight_1_0 = 0.0
linear.bias_0 = 5.0
```

Эта штука задаёт функцию `sigmoid(-10 * x1 + 5)`, граница решения которой проходит по прямой `x1 = 0.5`.
